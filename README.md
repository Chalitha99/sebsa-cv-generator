# Sebsa CV Generator

A modern CV (resume) generation application built with **Next.js** and **Tailwind CSS**. Sebsa CV Generator helps users create professional CVs with a clean, responsive, and user-friendly interface.

## 🚀 Features

* ✨ Modern and responsive user interface
* 📄 Professional CV generation
* 🎨 Tailwind CSS-based styling
* ⚡ Fast performance with Next.js
* 🧩 Reusable React components
* 📱 Mobile-friendly design
* 🖨️ CV preview and printable layouts
* 🔧 Easy customization and future expansion

## 🛠️ Tech Stack

* **Framework:** Next.js
* **Frontend:** React
* **Styling:** Tailwind CSS
* **Language:** JavaScript / TypeScript
* **Package Manager:** npm

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/sebsa-cv-generator.git
```

### Navigate to the project folder

```bash
cd sebsa-cv-generator
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
